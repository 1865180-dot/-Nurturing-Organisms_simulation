# 生物育成シミュレーター

中学校技術・家庭科（技術分野）「C 生物育成の技術」の授業用シミュレーションです。
ミニトマト（作物の栽培）・マダイ（水産生物の栽培）・採卵鶏（動物の飼育）の育成を、生産者になったつもりで体験できます。

- `index.html`：アプリ本体
  - 育成計画の選択肢ごとに「よい面 ⇔ マイナスの面（トレードオフ）」を表示
  - 育成中に3回の「技術ガチャ」（レア・スーパーレア・レジェンドレアの実在の技術）
  - 途中で1回の「経営の大勝負」（契約販売で安全に／市場に賭ける）
  - 結果画面に「経営のバランス（収入・環境・生き物の健康・省力）」を表示
- `images/`：写真（AIで生成した画像、軽量化済み）
- `コード.gs`：記録をGoogleスプレッドシートに提出するためのApps Script

ガイダンス用のすごろく「いのちの1万年すごろく」は、別のリポジトリ [seibutsu_introduction](https://github.com/1865180-dot/seibutsu_introduction) にあります。
