# 生物育成シミュレーター

中学校技術・家庭科（技術分野）「C 生物育成の技術」の授業用シミュレーションです。
ミニトマト（作物の栽培）・マダイ（水産生物の栽培）・採卵鶏（動物の飼育）の育成を、生産者になったつもりで体験できます。

- `index.html`：アプリ本体
  - 育成計画の選択肢ごとに「よい面 ⇔ マイナスの面（トレードオフ）」を表示
  - 育成中に3回の「技術ガチャ」（レア・スーパーレア・レジェンドレアの実在の技術）
  - 途中で1回の「経営の大勝負」（契約販売で安全に／市場に賭ける）
  - 結果画面に「経営のバランス（収入・環境・生き物の健康・省力）」を表示
- `images/`：写真（AIで生成した画像、軽量化済み）

ガイダンス用のすごろく「いのちの1万年すごろく」は、別のリポジトリ [seibutsu_introduction](https://github.com/1865180-dot/seibutsu_introduction) にあります。

## 主人公
プレイヤーはノベルゲーム「生物育成ストーリーズ」に登場する**道の駅の社長**です。各ターンで社長がひとこと話し、状況（お金・生き物の健康）に合わせて表情が変わります。

氏名入力・目標や理由の記入・振り返りの記入・スプレッドシートへの提出はありません。題材を選ぶとすぐに始まります。

## お客さんからの注文
ゲーム開始時に、お客さん（レストラン・給食センター・料亭・ケーキ屋など）から注文が1つ届きます。毎ターン、達成状況（✅達成中／⏳まだ）が表示されます。出荷の日に達成していれば、売り上げの15％の特別ボーナスがもらえて、爆売れしやすくなります。達成できないと信用が下がり、売れ残りやすくなります。

## 出荷の日
最後のターンのあとに「出荷の日」があります。

1. **値段を決める**：💎高め（×1.4・売れ残りやすい）／⚖️ふつう／🏷️安め（×0.75・爆売れしやすい）
2. **売れ行き**がランダムに3段階で決まります。

| 結果 | 売り上げ |
|---|---|
| 😢 売れ残り | ×0.7 |
| 😊 完売 | ×1 |
| 🤩 爆売れ | ×2.2 |

生き物の健康を高く保つほど、また注文を達成するほど、爆売れが出やすくなります。
